# WeBWorK: Hide Previous Answers

Tampermonkey userscript that hides previous answers and feedback on WeBWorK problems in order to redo past assignments as study material.

## Installation

1. Install [Tampermonkey](https://www.tampermonkey.net/) in your browser.
2. Allow user scripts (Chromium browsers only):
   - Open `chrome://extensions` (Edge: `edge://extensions`, Brave: `brave://extensions`).
   - Find **Tampermonkey** and click **Details**.
   - Turn on **Allow User Scripts**. If you don't see this switch, turn on **Developer mode** instead.
4. Open the raw script file:
   [`webwork-hide-answers.user.js`](https://raw.githubusercontent.com/chalcosoma/hide-webwork-answers/refs/heads/main/hide-webwork-answers.user.js)
5. Tampermonkey will show an install page. Click **Install**.

You can also create a new script in the Tampermonkey dashboard and paste the code in.
